# HookLens 공부 노트

1차 MVP를 만들면서 배운 것과 결정한 이유를 정리한 문서. 면접 준비용.
(최종 갱신: REQ-HOOK-002 완료 시점)

## 1. 무엇을 만드나

**웹훅을 받아 주는 "임시 우체통".**

결제사·깃허브 같은 외부 서비스는 어떤 일이 생기면 우리 서버로 HTTP 요청(웹훅)을 보낸다.
개발 중에는 "실제로 뭐가 오는지" 보기 어렵다.
HookLens는 고유 주소(`/h/abc123XYZ`)를 만들어 주고, 거기로 오는 요청을 전부 기록해서 보여 주고, 원하는 응답을 돌려준다.

## 2. 지금까지 완성된 흐름

```
① 주소 발급          ② 웹훅 도착            ③ 기록              ④ 응답
POST /api/endpoints → POST /h/{slug}/... → request_log 저장 → 규칙대로 응답
(slug + 토큰 받음)    (아무 메서드나 OK)    (헤더·바디 등 전부)   (없으면 200 {"ok":true})
```

| 기능 | 쉽게 말하면 | PR |
| --- | --- | --- |
| REQ-EP-001 | 우체통 하나 만들어 주기 (주소 + 열쇠) | 초기 커밋 |
| REQ-EP-002 | 비회원 우체통은 24시간 뒤 문 닫기 (그 뒤엔 410) | 초기 커밋 |
| REQ-HOOK-001 | 우체통에 들어온 편지를 그대로 보관 | #1 |
| REQ-HOOK-002 | 편지를 받으면 정해 둔 답장 보내기 (지연 가능) | #2 |

## 3. 기능별 정리

### ① 엔드포인트 발급 (REQ-EP-001)
- **slug**: 영숫자 10자 랜덤 주소. 경우의 수 62¹⁰ ≈ 8×10¹⁷이라 추측 불가. `Random`이 아니라 `SecureRandom` 사용(`Random`은 다음 값 예측 가능).
- **익명 토큰**: 로그인 없이 "이 우체통 주인은 나"를 증명하는 열쇠. 처음 한 번만 보여 주고 DB에는 SHA-256 해시만 저장.
- 숫자 id 대신 slug만 외부에 노출 → 순번이면 남의 엔드포인트를 추측할 수 있음.
- slug 중복은 "미리 확인 후 최대 3번 재시도" + "DB 유니크 제약" 두 겹으로 막는다.

### ② 만료 (REQ-EP-002)
- `Endpoint.isExpired(now)`: 만료 판단을 엔티티가 스스로 한다 → 규칙이 데이터 옆에 있어 여러 곳에 중복 구현되지 않음.
- 요청 시점에 판단 → 스케줄러가 "만료됨" 상태를 표시하는 방식보다 반영이 늦지 않고 컬럼도 덜 필요.
- 없는 주소는 404, 만료된 주소는 410.

### ③ 웹훅 수신·저장 (REQ-HOOK-001)
- `/h/{slug}/**`: 모든 메서드, 모든 하위 경로를 받는다.
- 메서드·경로·쿼리·헤더·바디·IP·시각을 가공하지 않고 그대로 저장 (디버깅 도구라 "받은 그대로"가 핵심).
- 바디는 한 번만 읽을 수 있는 스트림 → 원본 바이트를 직접 읽는다. 같은 이유로 `FormContentFilter`를 껐다(켜면 PUT 폼 바디가 비어 저장됨).
- 한계: 바이너리 바디는 UTF-8 문자열로 저장해 깨질 수 있음. IP는 배포 시 Nginx 뒤 실제 IP 처리 필요.

### ④ 설정된 응답 (REQ-HOOK-002)
```
컨트롤러: 요청 받음
  └ 서비스(@Transactional): 엔드포인트 확인 → 로그 저장 → 기본 규칙 조회 → 트랜잭션 끝(커밋)
컨트롤러: 규칙에 지연이 있으면 기다림 (가상 스레드)
  └ HookResponseBuilder: 규칙 있으면 규칙대로 / 없으면 200 {"ok":true}
```
- 응답 헤더 JSON은 `{"이름": "값"}` (요청 로그는 `{"이름": ["값"]}`). 사용자가 직접 입력하는 값이라 단순하게.
- `Content-Length`, `Transfer-Encoding` 같은 전송 제어 헤더는 무시.

## 4. 개념 사전

| 용어 | 쉬운 설명 |
| --- | --- |
| 엔티티 (`Endpoint`, `ResponseRule`) | DB 테이블 한 줄을 자바 객체로 표현한 것 |
| Repository | DB 창구. 메서드 이름만 쓰면 Spring이 SQL을 만들어 줌 (`findByEndpointIdAndIsDefaultTrue`) |
| Service | 실제 업무 로직 (확인 → 저장 → 조회) |
| Controller | HTTP 요청을 받고 응답을 돌려주는 입구 |
| `@Transactional` | 안의 DB 작업을 한 묶음으로 처리. 중간에 실패하면 전부 취소(롤백) |
| 생성자 주입 | `final` 필드 + `@RequiredArgsConstructor` → Spring이 필요한 객체를 넣어 줌. 바뀌지 않고 테스트에서 갈아 끼우기 쉬움 |
| `Optional` | "값이 없을 수도 있음"을 타입으로 알림 → null 실수 방지. 반환값에만 쓰고 파라미터로는 받지 않는다 |
| `map` / `orElseGet` | 값이 있으면 변환, 없으면 대체값. `orElse`는 값이 있어도 괄호 안을 먼저 실행하므로 `orElseGet` |
| `LAZY` 로딩 | 연관 객체는 실제로 쓸 때 불러옴. `open-in-view: false`라 트랜잭션이 끝난 뒤 접근하면 `LazyInitializationException` |
| `Clock` 빈 | 현재 시각을 한 곳에서 받음 → 테스트에서 시간 고정 가능 |
| 가상 스레드 | 기다리는 동안 OS 스레드를 놓아주는 가벼운 스레드 (식당 직원이 메모만 남기고 다른 테이블로 가는 비유) |
| Testcontainers | 테스트 때 진짜 MySQL을 Docker로 잠깐 띄워 검증 |
| Spring Data 메서드 이름 | getter가 아니라 **필드 이름** 기준으로 해석 (`isDefault` 필드 → `IsDefaultTrue`) |

## 5. 면접에서 설명할 결정들

1. **토큰 해시가 왜 BCrypt가 아니라 SHA-256?**
   BCrypt는 추측하기 쉬운 비밀번호를 일부러 느리게 만들어 막는 용도. 이 토큰은 32바이트 난수라 무차별 대입이 불가능하므로 빠른 해시로 충분하고, 같은 값이면 해시도 같아 바로 조회할 수 있다.
2. **지연을 왜 트랜잭션 밖에서 기다리나?**
   안에서 5초씩 기다리면 DB 커넥션(HikariCP 기본 10개)을 붙잡는다. 지연 요청 10개면 다른 요청까지 전부 멈춘다. 밖에서 기다리면 로그도 바로 보인다.
   → 이를 증명하는 테스트: "지연 응답을 기다리는 동안에도 로그는 이미 저장돼 있다".
3. **왜 가상 스레드?**
   대안: 그냥 `sleep`(톰캣 스레드 200개가 묶임), `DeferredResult` 비동기(코드 복잡). 가상 스레드는 코드는 단순한 `sleep`인데 기다리는 동안 OS 스레드를 놓아준다. 주의점(pinning: `synchronized` 안에서 기다리면 이점이 사라짐)은 우리 코드에 해당 없음(MySQL 드라이버 9.x도 해결됨).
4. **`Content-Length` 같은 헤더를 왜 막았나?**
   실제 바디 길이와 다르면 클라이언트가 응답을 끝까지 못 읽거나 잘린다. 서버가 직접 계산하게 둔다.
5. **`InterruptedException`을 잡으면 왜 `interrupt()`를 다시 부르나?**
   예외를 잡으면 중단 신호가 지워진다. 다시 살려 둬야 위쪽(톰캣)이 종료 중임을 알 수 있다.
6. **테스트를 왜 진짜 MySQL로?**
   H2 같은 인메모리 DB는 MySQL과 문법·동작이 달라 운영에서만 터지는 버그를 놓친다.
7. **SSE 인증은? (REQ-LOG-001 예정)**
   `EventSource`는 커스텀 헤더를 못 보낸다 → `fetch` 스트림으로 연결해 `X-Anonymous-Token` 헤더 인증을 그대로 쓴다. 쿼리 파라미터는 토큰이 Nginx 로그·브라우저 기록에 남고, 일회용 티켓은 저장소·재연결 처리가 필요하다.

## 6. 작업 방식
- **브랜치 → 커밋 → PR → merge**: 기능 하나마다 브랜치, PR로 main에 합친다.
- **CLAUDE.md**: 규칙과 진행 상황. 새 세션에서도 이걸 읽고 이어간다.
- **`.env`**: 비밀 값은 여기에만. Git에 올리지 않는다.
- **`.gitattributes`**: 줄바꿈을 LF로 고정 → Windows에서 커밋해도 리눅스 CI에서 `gradlew`가 돈다.
